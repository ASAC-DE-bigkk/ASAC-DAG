## 구성 방법 (나중에)

1. `<domain>-draft_patterns.yml` 의 "삽입 대상 모델: X" 섹션별 블록을 그 모델의 `usage_patterns`
   끝에 붙인다. (커머스 merge_candidates 와 동형 — `tools/merge_to_draft.py` 가 이 블록을 생성했다.)
2. CI 린트(공유)로 검증 → 게시기 배선이 있으면 게시 시 자동 감사.
3. verify 스탬핑(운영 D1) → 게이트웨이 실행 가능.

재현 도구는 `../tools/`: `dump_and_replica.py`(스키마 덤프+레플리카) · `briefing.md`(저작 규약) ·
`local_run.py`(레플리카 검증) · `verify_authored.py`(감사+실 D1 검증) · `merge_to_draft.py`(블록화).
